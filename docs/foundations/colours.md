## Overview

This document outlines the foundational colour palette used across the design system. It defines a structured set of colours categorized by their primary use cases, including functional colours for text and borders, brand-aligned primary and secondary palettes, and neutral grays for a wide range of applications, including a specific marketing gray. Adhering to these defined colours ensures visual consistency, reinforces brand identity, and contributes to a cohesive user experience.

## Usage Guidelines

The colour palette should be applied consistently across all design artifacts to maintain brand recognition and visual harmony.
*   **Text colours**: Use the designated colours for all textual content to ensure legibility and hierarchy.
*   **Border colours**: Apply these colours specifically for outlines, dividers, and container borders.
*   **Primary colours**: These are core brand colours, typically used for primary actions, branding elements, and key informational highlights.
*   **Secondary colours**: These provide visual variety and support the primary palette, suitable for supplementary actions, status indicators, or decorative elements.
*   **Gray colours**: Utilized for neutral backgrounds, subtle text, disabled states, and UI elements where a neutral tone is required.
*   **Marketing gray**: A specific gray variant intended for use in marketing and promotional materials, aligning with distinct brand marketing guidelines.

## Best Practices

*   **Consistency**: Always use the predefined colour tokens instead of arbitrary HEX or RGB values.
*   **Purpose-driven use**: Apply colours according to their intended categories (e.g., use "Text colours" for text, "Border colours" for borders).
*   **Brand alignment**: Prioritize primary colours for key branding elements and actions.
*   **Contrast**: Ensure sufficient colour contrast for text and interactive elements (see Accessibility section).

## Accessibility

The provided content does not include specific accessibility considerations regarding colour contrast ratios or colour blindness guidelines. However, general accessibility best practices for colour include:
*   Ensure a minimum contrast ratio of 4.5:1 for normal text and 3:1 for large text (WCAG 2.1 AA).
*   Avoid using colour alone to convey meaning; always supplement with text labels, icons, or patterns.
*   Test colour palettes with colour blindness simulators to ensure critical information is perceivable by all users.
