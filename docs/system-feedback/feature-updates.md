# Feature updates
```markdown
## Overview

These guidelines describe the recommended in-app communication strategies for informing users about different types of feature updates within the product. The goal is to provide appropriate guidance based on the scope and impact of the change, ensuring users are aware of new functionalities or alterations without causing unnecessary disruption.

## Usage Guidelines

The method of communicating a feature update should correspond to its nature and potential impact on the user's workflow. This section outlines different update types and their recommended in-app guidance.

### Feature Update Communication Matrix

| Update Type | Impact/Severity | Description | Recommended Guidance | Examples/Context |
| :---------- | :-------------- | :---------- | :------------------- | :--------------- |
| Minor aesthetic changes | Bronze | UI tweaks that do not fundamentally change how a feature functions or where it is accessed from. | No in-app guidance is required. | Button labelling, Colours, Illustrations, Layout (minor adjustments), Information Architecture (IA) changes in low-traffic areas. |
| Minor functional changes | Bronze | Changes to how a feature works that may disrupt the user's task flow. | Use pointer tours to highlight relevant parts of the product and educate the user about the changes. If the change is nested deeper within the product, provide context when the user navigates to that specific area. | Information Architecture (IA) changes in mid-to-high traffic areas, Layout (mid-to-major changes), Functional additions. |
| Major functional changes | Silver - Gold | Larger functional changes that require more extensive context and explanation to the user. | A mix of product tours, banners, and posts to communicate in-app. Communication strategy is typically heavily directed by Product Management (PM) and Product Marketing Management (PMM). | Content requiring significant explanation or involving multiple connected changes. |

## Best Practices

*   **Early Collaboration**: For functional changes, collaborate early with Product Management (PM) and Product Marketing Management (PMM) to raise potential impacts of these changes and align on communication strategies.
*   **Contextual Guidance**: When a change is nested deeper within the product, ensure context is provided to the user precisely when they navigate to that specific area.

## Variants/States

The guidelines define three main variants of feature updates based on their nature and impact: Minor Aesthetic, Minor Functional, and Major Functional, each requiring a different communication approach.

*   **Impact/Severity**: An internal grading system indicating the significance of the change (Bronze, Silver, Gold).
*   **Recommended Guidance**: The suggested in-app communication method(s) (e.g., no guidance, pointer tours, product tours, banners, posts, tooltips).
```
