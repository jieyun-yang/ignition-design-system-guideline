# Rich text editor
## Overview

The Rich Text Editor is a component designed for authoring and formatting text content. It provides users with a comprehensive set of tools to create rich, structured text, including capabilities for inserting placeholders, viewing and editing the underlying HTML source code, creating and managing tables, and applying text highlighting.

## Usage Guidelines

### When to use

*   To create terms, email, and message templates, including the insertion of placeholders.
*   To write messages and emails within the proposal editor when a pre-existing template is not being utilized.
*   For editing and updating service descriptions within the service library.

### When not to use

*   Avoid using the rich text editor for simple text input fields that do not require any formatting capabilities.

## Best Practices

### Do

*   Use the rich text editor in areas where text content can or needs to be formatted (e.g., bold, italics, lists, headers).

### Don't

*   Do not use the rich text editor for basic input fields where formatting options are unnecessary, as this can add unnecessary complexity to the user experience and interface.
